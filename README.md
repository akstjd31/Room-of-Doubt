# 🏚 Room of Doubt

Photon PUN2 기반의 3D 멀티플레이 방탈출 게임입니다.  

플레이어들은 협력하여 맵 곳곳의 퍼즐을 해결하고,  
아이템을 수집 및 공유하며 제한된 공간에서 탈출해야 합니다.

퍼즐 진행 상태, 아이템 정보, 결과 상태를 실시간으로 동기화하여  
모든 플레이어가 동일한 게임 진행 상황을 경험할 수 있도록 구현했습니다.

---

## 🎮 게임 플레이

- 멀티플레이 방 생성 및 입장
- 플레이어 협동 퍼즐 해결
- 아이템 획득 및 공유 인벤토리 관리
- 퀵슬롯을 통한 아이템 사용
- 모든 퍼즐 해결 시 탈출 가능
- 탈출 성공 시 게임 클리어

---

## 🛠 Tech Stack

- Unity 6000.2.10f1
- C#
- Photon PUN2

---

## 주요 구현 기능

### 1. Photon Custom Property 기반 퍼즐 동기화
퍼즐의 진행 상태를 Room Custom Property로 관리하여  
모든 플레이어가 동일한 퍼즐 상태를 확인할 수 있도록 구현했습니다.

- 퍼즐 완료 여부 동기화
- 상태 변경 이벤트 처리
- 늦게 접속한 플레이어 상태 동기화 대응

---

### 2. 공유 인벤토리 시스템
아이템 정보를 네트워크 상에서 공유하여  
모든 플레이어가 동일한 아이템 데이터를 사용할 수 있도록 구현했습니다.

- 아이템 획득 동기화
- 아이템 제거 동기화
- 공유 데이터 관리

---

### 3. 퀵슬롯 동기화 시스템
기존 로컬 기반 슬롯 구조에서 발생하던 동기화 문제를 해결하기 위해  
공유 인벤토리와 연결된 슬롯 구조로 개선했습니다.

- 슬롯 이동 동기화
- 아이템 사용 동기화
- UI 상태 동기화

---

## 기술적 문제 해결

### 문제
각 플레이어가 로컬에서 개별적으로 퀵슬롯을 관리하면서  
아이템 이동 시 서로 다른 데이터 상태가 발생했습니다.

### 해결
공유 인벤토리를 기준 데이터로 설정하고  
슬롯 이동 및 사용 이벤트를 네트워크 동기화 구조로 변경했습니다.

→ 플레이어 간 아이템 상태 불일치 문제 해결
